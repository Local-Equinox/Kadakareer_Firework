## ✨ About The Project

**Kadakareer_Firework** is a lightweight, engaging web application designed to bring celebrations right to your browser. By simply interacting with the page, users can trigger dynamic and colorful firework displays.

Whether you're testing out creative animations or just want a burst of digital color, this project delivers a fun and interactive visual treat!
